# journey — خط مترو للمهمة التي تعمل عليها

[English](README.md) · **العربية**

كل محطة من الآن حتى الانتهاء، وفي أي محطة تقف الجلسة الآن، و**لماذا**. تُرسم على شكل خط مترو في لوحة جانبية، وتُثبَّت في سطر الحالة أسفل مربع الكتابة.

</div>

<div dir="rtl">

<sub>اللوحة وسطر الحالة لمهمة تجريبية، كما يرسمها كود الإضافة نفسه.</sub>

اللون الأخضر هو ما مرّت به الجلسة، والباهت هو ما لم تصل إليه بعد. الرمز `◉` هو موقعها الآن. علامة `👤 your call` تعني محطة لا يتجاوزها إلا أنت، وعلامة `⏳ waiting on others` تعني محطة تنتظر شيئًا من خارج الجلسة، مثل CI أو نشر (deploy) أو مراجعة.

## لماذا تحتاجها

المهمة الطويلة في Claude Code تتحول إلى سيل من النصوص المتتابعة. تعود بعد عشر دقائق فلا تعرف ما الذي انتهى، ولا ما الذي يفعله Claude الآن، ولا إن كان ينتظرك. تجيب journey عن هذه الأسئلة الثلاثة بنظرة واحدة:

- **ما الذي أُنجز، وماذا كانت نتيجته.** لا تُعلَّم أي محطة كمنجزة دون ذكر ما خرجت به.
- **أين تقف الجلسة، ولماذا.** المحطة الحالية تذكر سبب وجود Claude فيها، وسبب وجودها على الخط أصلًا.
- **من عليه أن يتحرك الآن.** المحطات التي تحتاج قرارك تحمل علامة `👤 your call`، والمحطات التي تنتظر CI أو مراجعة تحمل علامة `⏳ waiting on others`.

وهي تُبقي Claude صادقًا أيضًا: المسار كله يُرسم قبل بدء العمل، فإذا تخطّى Claude خطوة ظهرت عليها علامة `⚠ passed, not marked` بدل أن تختفي بصمت.

## التثبيت

تحتاج إلى Claude Code مثبتًا على جهازك. افتح الطرفية (Terminal أو PowerShell) ونفّذ الخطوات التالية:

**١. أضف المتجر.** هذا الأمر يعرّف Claude Code بمستودع الإضافات على GitHub، ويكفي تنفيذه مرة واحدة:

</div>

```
claude plugin marketplace add AhmedQureshi89/mods
```

<div dir="rtl">

**٢. ثبّت الإضافة.** الاسم بعد علامة `@` هو اسم المتجر:

</div>

```
claude plugin install journey@ahmed-mods
```

<div dir="rtl">

**٣. ابدأ جلسة جديدة في Claude Code.** الإضافة تُحمَّل عند بداية الجلسة، فلن تظهر في جلسة كانت مفتوحة قبل التثبيت.

**٤. تأكد أنها تعمل.** اكتب الأمر التالي داخل Claude Code. إذا فُتحت لوحة عنوانها Journey ومكتوب فيها "No journey yet" فالتثبيت ناجح:

</div>

```
/journey
```

<div dir="rtl">

بديل أسرع: من داخل Claude Code نفسه (الإصدار 2.1.275 أو أحدث) يمكنك التثبيت بخطوة واحدة:

</div>

```
/plugin install journey --marketplace AhmedQureshi89/mods
```

<div dir="rtl">

### التحديث والإزالة

| ماذا تريد | الأمر |
|---|---|
| عرض الإضافات المثبتة | `claude plugin list` |
| التحديث إلى آخر إصدار | `claude plugin update journey@ahmed-mods` |
| الإزالة | `claude plugin uninstall journey@ahmed-mods` |

## طريقة الاستخدام

لا تحتاج إلى أي إعداد. الإضافة تعمل من تلقاء نفسها، وهذا ما يحدث عادةً:

**١. اطلب مهمة فيها عدة خطوات.** مثلًا: "أصلح خطأ انتهاء المهلة في صفحة الدفع، وافتح طلب دمج (PR)". الإضافة تضيف تعليمات قصيرة لـ Claude، فيرسم خط الرحلة قبل أن يبدأ العمل في أي مهمة تتجاوز خطوتين.

**٢. تُفتح اللوحة تلقائيًا** عند رسم أول خط في الجلسة. ترى فيها الهدف، وشريط التقدم، وكل المحطات بالترتيب.

**٣. تابع من اللوحة بدل قراءة كل الرسائل.** كل محطة تخبرك بشيء:

| ما تراه | معناه |
|---|---|
| `●` أخضر مع `✓` | محطة انتهت، والسطر تحتها يذكر نتيجتها |
| `◉` مع `YOU ARE HERE` | المحطة الحالية. "Why here" سبب وجود Claude فيها الآن، و"Why this stop" سبب وجودها على الخط |
| `○` باهت | محطة لم يصل إليها بعد، وتحتها سبب وجودها |
| `👤 your call` | محطة تنتظر قرارك أو عملك أنت |
| `⏳ waiting on others` | محطة تنتظر شيئًا خارجيًا، مثل CI أو نشر أو مراجعة |
| `◆` أحمر مع `⛔` | محطة متوقفة، والسطر تحتها يذكر ما يعيقها |
| `◌` مشطوب | محطة تُركت عمدًا، مع ذكر السبب |
| `⚠ passed, not marked` | محطة تجاوزها Claude دون أن يذكر ما حدث فيها |

**٤. انظر إلى سطر الحالة أسفل مربع الكتابة.** يعرض التقدم والمحطة الحالية حتى لو كانت اللوحة مغلقة، مثل `⏳ 3/6 · Wait for CI`.

**٥. غيّر المسار بكلامك العادي.** إذا أردت إضافة خطوة أو حذفها أو تغيير ترتيبها، فقل ذلك لـ Claude، وسيعيد رسم الخط. المحطات المنجزة تحتفظ بحالتها.

**٦. عند الانتهاء** يُغلق Claude الرحلة وتظهر علامة 🏁. لا يمكنه إغلاقها وفيها محطة لم تُحسم بعد.

### الأوامر

| الأمر | ماذا يفعل |
|---|---|
| `/journey` | يفتح اللوحة ويطبع الخط نصًا |
| `/journey plan <الهدف>` | يطلب من Claude رسم المسار لهذا الهدف، أو للمهمة الحالية إذا لم تذكر هدفًا |
| `/journey clear` | يحذف الرحلة الحالية |

### ملاحظات

- إذا استأنفت جلسة سابقة فستجد خطها كما تركته.
- الأمر `/clear` في Claude Code يحذف الرحلة مع المحادثة.
- الوكلاء الفرعيون (subagents) لا يحرّكون الخط. المحادثة الرئيسية وحدها تحرّكه.

## كيف تُغذّى

Claude هو من يرسم الخط، والإضافة لا تخمّن شيئًا. فهي تسجّل أداة اسمها `mcp__journey__line`، وتضيف فقرة قصيرة إلى تعليمات النظام حتى يرسم Claude المسار قبل أي مهمة تتجاوز خطوتين، ثم يحافظ على دقته.

| الإجراء | ماذا يفعل | ما الذي يشترطه |
|---|---|---|
| `plan` | يرسم المسار: هدفًا وكل المحطات (`id` و`title` و`why` و`who`). يُستدعى مرة أخرى عند تغيّر المسار، وتحتفظ المحطات بحالتها حسب المعرّف أو العنوان. | هدف، ومحطتان على الأقل |
| `arrive` | الجلسة تصل إلى محطة. | `note`: سبب الوجود فيها. التقدم إلى الأمام يحتاج أيضًا `outcome`: ما خرجت به المحطة السابقة. |
| `update` | يغيّر محطة. | الحالات `done` و`skipped` و`blocked` تحتاج كلٌّ منها `note`: لا تُعلَّم محطة دون ذكر ما حدث فيها. |
| `finish` | يغلق الرحلة. | يُرفض ما دامت هناك محطة بحالة `todo` أو `here` أو `blocked` |
| `clear` · `show` | يحذفها · يقرؤها. | |

المحطة التي تجاوزتها الجلسة دون تعليمها تظهر عليها علامة `⚠ passed, not marked` بدل أن تُحسب بصمت.

## ما الذي تحفظه

يُحفظ المسار في حالة الجلسة، فيبقى بعد إعادة تحميل الإضافة. ويُحفظ أيضًا في مخزن الإضافة تحت معرّف الجلسة، فتجده الجلسة المستأنفة. تُحفظ أحدث عشر رحلات فقط. لا تقرأ الإضافة ولا تكتب أي شيء آخر: لا ملفات، ولا عمليات، ولا اتصال بالشبكة.
